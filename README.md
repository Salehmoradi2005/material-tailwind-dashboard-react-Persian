## معرفی

این پروژه یک قالب مدیریتی (Admin Template) بر پایه‌ی React و Tailwind CSS است. اگر توسعه‌دهنده‌ای هستید که به‌دنبال ساخت یک داشبورد مدیریتی ساده برای توسعه، پرامکانات و کاملاً قابل‌شخصی‌سازی هستید، این پروژه می‌تواند نقطه‌ی شروع مناسبی باشد. طراحی آن از Material Design گوگل الهام گرفته شده و به شما کمک می‌کند وب‌سایت‌ها و برنامه‌های وب زیبایی بسازید.

**المان‌های کاملاً کدنویسی‌شده**

این پروژه با بیش از ۴۰ المان فرانت‌اند مجزا از کتابخانه‌ی `@material-tailwind/react` ساخته شده است؛ از جمله دکمه‌ها، ورودی‌ها، نوار ناوبری، تب‌های ناوبری، کارت‌ها و هشدارها (Alert). تمام کامپوننت‌ها از نظر رنگ قابل تغییر هستند و می‌توانید به‌راحتی با props و کلاس‌های Tailwind CSS آن‌ها را تغییر دهید. چون همه‌ی المان‌ها پیاده‌سازی شده‌اند، مسیر رفتن از نمونه‌ی اولیه تا کد کاملاً عملیاتی در زمان زیادی صرفه‌جویی می‌شود.

**صفحات نمونه**

پروژه شامل صفحات آماده‌ای مانند داشبورد، پروفایل، جداول، اعلان‌ها، ورود و ثبت‌نام است تا ساختار پایه‌ی پروژه‌ی وب خود را در زمان کوتاهی راه‌اندازی کنید.

#### تکنولوژی‌ها و ابزارهای استفاده‌شده

- [Material Tailwind](https://material-tailwind.com/) - کتابخانه‌ی کامپوننت برای Tailwind CSS و Material Design.
- [Hero Icons](https://heroicons.com/) - آیکون‌های SVG زیبا و دست‌ساز.
- [Apex Charts](https://apexcharts.com/) - نمودارهای مدرن و تعاملی متن‌باز.

## نصب و راه‌اندازی

1. نسخه‌ی LTS نرم‌افزار NodeJs را از [صفحه‌ی رسمی NodeJs](https://nodejs.org/en/download/) دانلود و نصب کنید.
2. به پوشه‌ی اصلی (root) پروژه بروید و برای نصب وابستگی‌ها، یکی از دستورات `npm install` یا `yarn install` یا `pnpm install` را اجرا کنید.
3. برای اجرای پروژه در حالت توسعه، دستور `npm run dev` را اجرا کنید.
